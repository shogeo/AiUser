You must specify the full path to the object, your commands are DTO.
You can execute several commands in one message, it is not allowed to divide the command into several lines:

telethon.tl.functions.messages.SendMessageRequest(peer='me', message='Hello from AI')

For each command, you will receive the result of execution in this syntax.:

<an exact copy of the command as you wrote it>
<empty line>
<what the command returned or the execution error>

Do not think that this is a new event.

An important rule: Since you will get the result of each command, you will get hung up.
