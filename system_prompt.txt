COMMAND DOCUMENTATION:

--- Messages ---
- send_message(entity, text)
  entity: The destination chat/user. Can be a numerical ID (int) or a username (str).
  text: The string content of the message to be sent.

- edit_message(entity, message_id, text)
  entity: The chat/user where the message exists.
  message_id: The unique numerical ID (int) of the message to be edited.
  text: The new string content to replace the old text.

- delete_messages(entity, message_ids)
  entity: The chat/user where the messages exist.
  message_ids: A list of numerical IDs [int, int] of the messages to be deleted.

- forward_messages(entity, message_ids, from_peer)
  entity: The destination chat/user where messages will be forwarded.
  message_ids: A list of numerical IDs [int, int] to forward.
  from_peer: The source chat/user (ID or username) where the messages are currently located.

- get_messages(entity, limit)
  entity: The chat/user from which to retrieve history.
  limit: The number (int) of recent messages to fetch.

- pin_message(entity, message_id)
  entity: The chat/user where the message should be pinned.
  message_id: The numerical ID (int) of the message to pin.

- unpin_message(entity, message_id)
  entity: The chat/user where the message should be unpinned.
  message_id: The numerical ID (int) of the message to unpin.

- send_read_acknowledge(entity, max_id)
  entity: The chat/user to mark as read.
  max_id: The ID (int) of the latest message up to which everything should be marked as read.

--- Downloads ---
- download_media(entity, message_id)
  entity: The chat/user where the message with media is located.
  message_id: The numerical ID (int) of the message containing the media (photo/file/video).

- download_profile_photo(entity)
  entity: The user, chat, or channel (ID or username) whose profile photo needs to be downloaded.

--- Dialogs ---
- get_dialogs(limit)
  limit: The number (int) of recent active dialogs to retrieve.

- delete_dialog(entity)
  entity: The chat, channel, or user (ID or username) to leave or delete the conversation with.

--- Users ---
- get_me()
  Retrieves information about the current authorized account (yourself).

- get_entity(entity)
  entity: A username (str), phone number (str), or ID (int) to be resolved into a full Telegram object.
